# Nebula OS

Nebula OS - это браузерная операционная система, сделанная только на **HTML, CSS и JavaScript**. Проект имитирует рабочий стол настоящей ОС: загрузку, окна, dock/taskbar, приложения, настройки, уведомления, виртуальную файловую систему и системный монитор.

Проект не использует React, Vue, Angular, jQuery, npm-библиотеки, сборщики, TypeScript или backend. Его можно открыть напрямую через `index.html`.

## Быстрый запуск

Откройте файл:

```text
index.html
```

- анимированный логотип Nebula;
- прогресс загрузки от 0 до 100%;

- parallax-эффект при движении мыши;

- выделение области мышью;

- смена обоев;

### Оконный менеджер

**Терминал**

## Архитектура

Проект построен вокруг самостоятельных модулей.

### EventBus

`js/core/EventBus.js` отвечает за связь между частями системы. Приложения и компоненты не вызывают друг друга напрямую, а отправляют события:

```text
app:open
window:focus
window:restore
window:close
theme:changed
```

### Store

`js/core/Store.js` хранит состояние системы:

- открытые окна;
- активное окно;
- текущую тему;
- текущие обои;
- прозрачность окон;
- настройки анимаций и звука.

Часть состояния сохраняется в `localStorage`, поэтому настройки остаются после перезагрузки страницы.

### WindowManager

`js/components/WindowManager.js` управляет окнами:

- создает окно;
- регистрирует приложение внутри окна;
- перемещает окно;
- меняет размер;
- сворачивает;
- разворачивает;
- закрывает;
- переключает фокус;
- раскладывает окна сеткой.

### Component

`js/core/Component.js` - базовый класс для приложений. Он помогает хранить обработчики событий и корректно очищать их при закрытии окна.

### Утилиты

В `js/utils/` находятся небольшие помощники:

- `debounce` для оптимизации частых событий;
- `throttle` для плавных drag/resize-операций;
- `memoize` для кеширования;
- `format` для времени, даты и HTML-экранирования;
- `validators` для проверки тем, обоев и приложений.

## Производительность

Для плавной работы используются:

- `requestAnimationFrame` внутри throttle;
- ограничение частоты drag/resize;
- CSS-анимации на `transform` и `opacity`;
- минимальное количество глобальных перерисовок;
- Canvas только для графиков системного монитора;
- сохранение только нужных настроек в `localStorage`.

## Безопасность

Проект не выполняет пользовательский HTML. Текст, который попадает в интерфейс, экранируется через `Nebula.format.escapeHTML`.

Калькулятор проверяет выражение регулярным выражением и допускает только цифры, пробелы, скобки и базовые математические операторы.

## Совместимость

Проект ориентирован на современные браузеры:

- Chrome 90+;
- Firefox 88+;
- Safari 14+;
- Edge на Chromium.

Так как проект не использует ES Modules, его можно открыть напрямую через `file://`.

## Ограничения

- Файловая система виртуальная, реальные файлы с диска не читаются.
- Системный монитор имитирует показатели CPU/RAM.
- Многозадачность демонстрационная, внутри одного браузерного процесса.
- WebAudio может заработать только после пользовательского действия, если браузер блокирует автозвук.

## Проверка

Для проверки синтаксиса JavaScript можно выполнить:

```bash
node --check js/main.js
```

Или проверить все JS-файлы в PowerShell:

```powershell
Get-ChildItem -Recurse -File js | ForEach-Object { node --check $_.FullName }
```

Проект не требует установки зависимостей.

## Сценарий демонстрации

1. Открыть `index.html` и показать boot screen.
2. Показать рабочий стол, виджеты и смену обоев.
3. Открыть Nebula Launcher через кнопку `N` или `Ctrl + Space`.
4. Запустить терминал и выполнить:

```text
help
neofetch
ps
open files
theme light
wallpaper sunset
```

5. Открыть несколько окон, перетащить их и изменить размер.
6. Выполнить команду `tile` или действие "Уложить окна" в launcher.
7. Открыть настройки, включить звук, отправить тестовое уведомление.
8. Открыть файловый менеджер, создать файл и папку, показать инспектор.
9. Открыть системный монитор и показать Canvas-графики.
10. Коротко показать структуру кода: `EventBus`, `Store`, `WindowManager`, `apps`.
